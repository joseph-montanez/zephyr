# Engineering Specification: AutoCAD LT Layout Page Setup Subsystem

## 1. Architectural Overview: Page Setups Decouple Layout Geometry from Output Device Configurations

In AutoCAD and AutoCAD LT, a **Page Setup** encapsulates all plotting, media, scaling, and pen-assignment parameters required to render a Paper Space layout (or Model Space) onto physical or virtual media ([AutoCAD LT Page Setup Dialog Box](https://help.autodesk.com/view/ACDLT/2026/ENU/?caas=caas/documentation/ACD/2014/ENU/files/GUID-D8BE8598-D9F8-49C2-81BC-19786A390379-htm.html)). For a CAD application that already supports Paper Space entities and viewports (`VIEWPORT`), implementing the Page Setup subsystem establishes the physical sheet boundary, the printable area (margin box), real-world paper units (`inches` or `mm`), and pen/style rendering rules on the layout canvas.

At the database level, AutoCAD implements an inheritance hierarchy where every Paper Space layout (`AcDbLayout` / DXF `LAYOUT` object) derives directly from `AcDbPlotSettings` (DXF `PLOTSETTINGS` object) ([LAYOUT DXF Reference](https://help.autodesk.com/view/OARX/2022/KOR/?caas=caas/documentation/ACDLT/2013/KOR/files/GUID-433D25BF-655D-4697-834E-C666EDFD956D-htm.html), [PLOTSETTINGS DXF Reference](https://help.autodesk.com/view/OARX/2022/KOR/?caas=caas/documentation/ACDLT/2013/KOR/files/GUID-1113675E-AB07-4567-801A-310CDE0D56E9-htm.html)):

* **Per-Layout Embedded Settings (`AcDbLayout`)**: Each layout tab owns its own `AcDbPlotSettings` base data stored in the `ACAD_LAYOUT` dictionary. Even when no named page setup is assigned (`<None>`), the layout holds a complete set of plot settings.
* **Named Page Setups (`AcDbPlotSettings`)**: Reusable, named presets are stored in the drawing's `ACAD_PLOTSETTINGS` dictionary ([To Work with Named Page Setups for Plotting](https://help.autodesk.com/view/ACDLT/2026/ENU/?caas=caas/documentation/ACD/2014/ENU/files/GUID-62B163D7-92F5-4793-85C2-246BDDA81470-htm.html)). Applying a named page setup to a layout copies the named `AcDbPlotSettings` fields into the layout's `AcDbPlotSettings` sub-object and records the named setup association in the `AcDbPlotSettings` subclass Group Code `1` (`pageSetupName`) ([ezdxf Layout Management Structures](https://ezdxf.readthedocs.io/en/stable/dxfinternals/layout_management.html)). Editing a named page setup in the Page Setup Manager propagates the updated settings to all layouts currently bound to that `pageSetupName`.
* **Model Space vs. Paper Space Scoping**: Named page setups carry a `ModelType` bitflag (DXF Group Code `70`, bit `1024`) ([PLOTSETTINGS DXF Reference](https://help.autodesk.com/view/OARX/2022/KOR/?caas=caas/documentation/ACDLT/2013/KOR/files/GUID-1113675E-AB07-4567-801A-310CDE0D56E9-htm.html)). Page setups created while a layout tab is active are scoped strictly to Paper Space layouts and only appear when the [Page Setup Manager](https://help.autodesk.com/view/ACDLT/2026/ENU/?caas=caas/documentation/ACD/2014/ENU/files/GUID-B06031A0-EF7E-4287-8E34-ABDCC40FF8C4-htm.html) is opened from a layout tab.

### UI Control Dependency & State Matrix

Implementing the Page Setup dialog requires enforcing AutoCAD's interactive enable/disable and auto-calculation rules whenever a user changes a control:

1. **When `Printer/plotter` changes**:
   * Reload the `Paper size` list from the new device's supported media.
   * Show/enable the `PDF Options...` button if and only if the driver is an Autodesk/built-in PDF driver; hide or disable it for non-PDF plotters ([Export to DWF/PDF Options Dialog Box](https://help.autodesk.com/view/ACDLT/2026/ENU/?caas=caas/documentation/ACDLT/2014/ENU/files/GUID-027CAE58-F0DA-4287-BD9E-12BDC31FF019-htm.html)).
   * Check whether the layout's previously selected paper size is supported by the new device. If unsupported and `PAPERUPDATE = 0`, display a warning dialog and select the closest or default paper size; if `PAPERUPDATE = 1`, silently switch to the plotter's default paper size ([PAPERUPDATE System Variable](https://help.autodesk.com/view/ACD/2026/ENU/?caas=caas/documentation/ACDLT/2014/ENU/files/GUID-35A66DE6-B442-43E3-B62C-BF204D45EC0E-htm.html)).
2. **When `Paper size` changes**:
   * Automatically set the `Plot scale` unit dropdown (`mm`, `inches`, or `pixels`) to match the native units of the selected media (`mm` for ISO/metric sheets like `ISO full bleed A3 (420.00 x 297.00 MM)`, `inches` for ANSI/Arch sheets, `pixels` for raster plotters) ([Page Setup Dialog Box](https://help.autodesk.com/view/ACDLT/2026/ENU/?caas=caas/documentation/ACD/2014/ENU/files/GUID-D8BE8598-D9F8-49C2-81BC-19786A390379-htm.html)).
   * Recompute printable margins (`DXF 40, 41, 42, 43`) and refresh the `Partial Preview` widget.
3. **When `What to plot` (`Plot area`) changes**:
   * **`Layout` selected**: Force `Fit to paper` to unchecked and **disable** `Fit to paper`; force `Center the plot` to unchecked and **disable** `Center the plot` (in `Layout` mode, the plot area is strictly the printable area anchored at `(0,0)` plus `[X, Y]` offset, and AutoCAD plots at `1:1` unless a custom scale is set) ([Page Setup Dialog Box](https://help.autodesk.com/view/ACDLT/2026/ENU/?caas=caas/documentation/ACD/2014/ENU/files/GUID-D8BE8598-D9F8-49C2-81BC-19786A390379-htm.html)).
   * **`Extents`, `Display`, `View`, or `Window` selected**: Enable `Fit to paper` and `Center the plot` (as seen in the user's screenshot where `What to plot` is `Extents` and `Center the plot` is checked with `X = -187.25 mm`, `Y = -128.88 mm`).
4. **When `Center the plot` is checked**:
   * Disable manual editing of `Plot offset X` and `Y` text boxes and dynamically compute `X` and `Y` whenever paper size, plot area, or plot scale changes:
     $$\text{Offset}_X = \frac{W_{\text{printable}} - (W_{\text{plotArea}} \times S)}{2}, \quad \text{Offset}_Y = \frac{H_{\text{printable}} - (H_{\text{plotArea}} \times S)}{2}$$
     where $S = \frac{\text{PaperUnits}}{\text{DrawingUnits}}$ is the effective plot scale factor. If `PLOTOFFSET = 1` (origin set to edge of paper), add the left/bottom unprintable margins to the offset ([PLOTOFFSET System Variable](https://help.autodesk.com/view/ACDLT/2027/ENU/?caas=caas/documentation/CIV3D/2014/ENU/filesACD/GUID-6890E492-8774-4DFA-B808-9E179431E84B-htm.html)).
5. **When `Plot with plot styles` is toggled**:
   * Checking `Plot with plot styles` automatically checks `Plot object lineweights`. Unchecking `Plot object lineweights` is allowed independently, whereas unchecking `Plot with plot styles` disables pen table overrides during plotting while retaining object lineweights if `Plot object lineweights` remains checked ([Page Setup Dialog Box](https://help.autodesk.com/view/ACDLT/2026/ENU/?caas=caas/documentation/ACD/2014/ENU/files/GUID-D8BE8598-D9F8-49C2-81BC-19786A390379-htm.html)).
6. **When `Shaded viewport options -> Quality` changes**:
   * `Draft` sets DPI display to `0` (wireframe); `Preview` caps at `150 DPI` (1/4 device resolution); `Normal` caps at `300 DPI` (1/2 device resolution, or `100 DPI` when device reference resolution is `200 DPI` as shown in the screenshot for `DWG To PDF.pc3`); `Presentation` caps at `600 DPI`; `Maximum` uses full device resolution; only `Custom` enables the `DPI` numeric input field (`100` to `32767`) ([Page Setup Dialog Box](https://help.autodesk.com/view/ACDLT/2026/ENU/?caas=caas/documentation/ACD/2014/ENU/files/GUID-D8BE8598-D9F8-49C2-81BC-19786A390379-htm.html), [PLOTSETTINGS DXF Reference](https://help.autodesk.com/view/OARX/2022/KOR/?caas=caas/documentation/ACDLT/2013/KOR/files/GUID-1113675E-AB07-4567-801A-310CDE0D56E9-htm.html)).

## 4. Paper Space Canvas Rendering: How Page Setup Drives Visual Sheet Geometry

Once a user clicks `OK` in the Page Setup Dialog Box (or `Set Current` in the Page Setup Manager), the CAD application's Paper Space canvas renderer must update four visual layers tied to the layout's `AcDbPlotSettings` ([Page Setup Dialog Box](https://help.autodesk.com/view/ACDLT/2026/ENU/?caas=caas/documentation/ACD/2014/ENU/files/GUID-D8BE8598-D9F8-49C2-81BC-19786A390379-htm.html), [ezdxf Layout Management Structures](https://ezdxf.readthedocs.io/en/stable/dxfinternals/layout_management.html)):

1. **Physical Paper Sheet Background & Drop Shadow**:
   * Convert physical millimeter dimensions (`DXF 44` width, `DXF 45` height) to layout paper units via `Code 72` ($S_{\text{unit}} = 1.0$ for `mm`, $25.4$ for `inches`, or multiply by `Code 147`), and scale by the inverse of the custom plot scale ($\frac{\text{DXF 143}}{\text{DXF 142}}$, which equals $1.0$ at the default `1:1` layout scale, or e.g. $50.0$ at `1:50` so title blocks drawn at model-like units frame inside the sheet) ([ezdxf Layout Management Structures](https://ezdxf.readthedocs.io/en/stable/dxfinternals/layout_management.html)):
     $$W_{\text{unrotated}} = \frac{\text{DXF 44}}{S_{\text{unit}}} \times \frac{\text{DXF 143}}{\text{DXF 142}}, \quad H_{\text{unrotated}} = \frac{\text{DXF 45}}{S_{\text{unit}}} \times \frac{\text{DXF 143}}{\text{DXF 142}}$$
   * When oriented in `Portrait` (`DXF 73 = 0` or `2`), $W_{\text{sheet}} = W_{\text{unrotated}}$ and $H_{\text{sheet}} = H_{\text{unrotated}}$. When oriented in `Landscape` (`DXF 73 = 1` or `3`), swap width and height so $W_{\text{sheet}} = H_{\text{unrotated}}$ and $H_{\text{sheet}} = W_{\text{unrotated}}$.
2. **Printable Area Dashed Boundary & 4-State Margin Permutation**:
   * Unprintable margins `DXF 40` ($M_L$), `DXF 41` ($M_B$), `DXF 42` ($M_R$), and `DXF 43` ($M_T$) are stored in millimeters relative to the **unrotated** sheet. After converting to scaled paper units, permute them by `PlotRotation` (`DXF 73`) before insetting the dashed printable rectangle ([PLOTROTMODE System Variable](https://help.autodesk.com/view/ACDLT/2027/ENU/?caas=caas/documentation/CIV3D/2014/ENU/filesACD/GUID-B376D968-4346-4D7E-9AE5-3888317B5730-htm.html)):
     * `Code 73 = 0` (`0°` Portrait): $(\text{Left}, \text{Bottom}, \text{Right}, \text{Top}) = (M_L, M_B, M_R, M_T)$
     * `Code 73 = 1` (`90° CCW` Landscape): $(\text{Left}, \text{Bottom}, \text{Right}, \text{Top}) = (M_T, M_L, M_B, M_R)$
     * `Code 73 = 2` (`180°` Upside-down Portrait): $(\text{Left}, \text{Bottom}, \text{Right}, \text{Top}) = (M_R, M_T, M_L, M_B)$
     * `Code 73 = 3` (`90° CW` Upside-down Landscape): $(\text{Left}, \text{Bottom}, \text{Right}, \text{Top}) = (M_B, M_R, M_T, M_L)$
3. **Paper Space Origin `(0,0)` Placement & `LIMMIN`/`LIMMAX` Synchronization**:
   * By default (`PLOTOFFSET = 0`), the Paper Space coordinate origin `(0,0)` sits at the **lower-left corner of the dashed printable area** offset by `(-PlotOriginX, -PlotOriginY)` (`DXF 46, 47`) ([PLOTOFFSET System Variable](https://help.autodesk.com/view/ACDLT/2027/ENU/?caas=caas/documentation/CIV3D/2014/ENU/filesACD/GUID-6890E492-8774-4DFA-B808-9E179431E84B-htm.html)). When `PLOTOFFSET = 1`, `(0,0)` is measured relative to the **lower-left physical edge of the paper sheet**.
   * Whenever paper size, margins, rotation, or plot scale change, synchronize `AcDbLayout` `LIMMIN` (`DXF 10, 20`) and `LIMMAX` (`DXF 11, 21`) to the lower-left and upper-right physical paper corners in scaled paper units relative to the plot origin ([ezdxf Layout Management Structures](https://ezdxf.readthedocs.io/en/stable/dxfinternals/layout_management.html)).
4. **Live Plot Style Preview (`Display plot styles`)**:
   * When `Display plot styles` (`DXF 70` bit `2`) is checked, the Paper Space viewport renderer evaluates the assigned `.ctb` or `.stb` table for every entity in Paper Space and inside activated Model Space viewports—substituting monochrome/grayscale/mapped colors, screening percentages, and pen lineweights on screen ([Page Setup Dialog Box](https://help.autodesk.com/view/ACDLT/2026/ENU/?caas=caas/documentation/ACD/2014/ENU/files/GUID-D8BE8598-D9F8-49C2-81BC-19786A390379-htm.html)).

## 6. Persistence & DXF/DWG Serialization Schema (`AcDbPlotSettings` & `AcDbLayout`)

To maintain full round-trip compatibility with AutoCAD and AutoCAD LT `.dwg`/`.dxf` files, both standalone named page setups (in `ACAD_PLOTSETTINGS`) and layout objects (in `ACAD_LAYOUT`) must read and write the `AcDbPlotSettings` group codes ([PLOTSETTINGS DXF Reference](https://help.autodesk.com/view/OARX/2022/KOR/?caas=caas/documentation/ACDLT/2013/KOR/files/GUID-1113675E-AB07-4567-801A-310CDE0D56E9-htm.html), [LAYOUT DXF Reference](https://help.autodesk.com/view/OARX/2022/KOR/?caas=caas/documentation/ACDLT/2013/KOR/files/GUID-433D25BF-655D-4697-834E-C666EDFD956D-htm.html)).

> **Critical DXF Subclass Collision Rule (`AcDbPlotSettings` vs. `AcDbLayout`)**: Inside a DXF `LAYOUT` entity, Group Codes **`1`**, **`70`**, and **`76`** appear **twice**—once after `100 = AcDbPlotSettings` and again after `100 = AcDbLayout` ([LAYOUT DXF Reference](https://help.autodesk.com/view/OARX/2022/KOR/?caas=caas/documentation/ACDLT/2013/KOR/files/GUID-433D25BF-655D-4697-834E-C666EDFD956D-htm.html), [ezdxf Layout Management Structures](https://ezdxf.readthedocs.io/en/stable/dxfinternals/layout_management.html)). Readers and writers must maintain a strict two-state split at the `100 = AcDbLayout` marker:
> * **Before `100 = AcDbLayout` (`AcDbPlotSettings` section)**: Code `1` = assigned Named Page Setup name (`""` if `<None>`), Code `70` = `PlotLayoutFlags` bitmask, Code `76` = `ShadePlotMode` (`0`–`3`).
> * **After `100 = AcDbLayout` (`AcDbLayout` section)**: Code `1` = Layout tab name (e.g., `Layout1`), Code `70` = Layout flags (`1` = `PSLTSCALE`, `2` = `LIMCHECK`), Code `76` = UCS orthographic type (`0`–`6`).

| DXF Group Code | Data Type | Field Name | Description & Valid Values |
| :--- | :--- | :--- | :--- |
| `100` | String | Subclass Marker | Always `AcDbPlotSettings` ([PLOTSETTINGS DXF Reference](https://help.autodesk.com/view/OARX/2022/KOR/?caas=caas/documentation/ACDLT/2013/KOR/files/GUID-1113675E-AB07-4567-801A-310CDE0D56E9-htm.html)). |
| `1` | String | Page Setup Name | Name of the named page setup in `ACAD_PLOTSETTINGS` (e.g., `A1 PDF`), or the assigned named setup inside a `LAYOUT`'s `AcDbPlotSettings` section (`""` when `<None>`) ([ezdxf Layout Management Structures](https://ezdxf.readthedocs.io/en/stable/dxfinternals/layout_management.html)). |
| `2` | String | Plot Config Name | System printer name or `.pc3` filename (e.g., `DWG To PDF.pc3`). |
| `4` | String | Canonical Media Name | Internal locale-independent media identifier (e.g., `ISO_full_bleed_A3_(420.00_x_297.00_MM)`), which the UI translates to a localized display name via `PlotSettingsValidator.GetLocaleMediaName` ([PlotSettingsValidator Reference](https://help.autodesk.com/cloudhelp/2024/ENU/OARX-ManagedRefGuide/files/OARX-ManagedRefGuide-Autodesk_AutoCAD_DatabaseServices_PlotSettingsValidator_SetPlotConfigurationName_PlotSettings_string_string.html)). |

## 7. Phased Implementation Roadmap for Your CAD Application

To bring full AutoCAD LT Page Setup support into an existing Paper Space implementation cleanly, build the subsystem in five incremental milestones:

1. **Phase 0: Full-Fidelity Model & Lossless DXF/EAB Round-Trip (`CADPlotSettings`)**
   * Replace the partial layout settings struct with a complete `CADPlotSettings` value type covering all DXF Group Codes (`1`–`149`), the full 0–32 `StandardScale` table, `useStandardScale` (`Code 70` bit `16`), and `pageSetupName` (`AcDbPlotSettings` Code `1`).
   * Preserve the strict two-state subclass split (`100 = AcDbPlotSettings` vs. `100 = AcDbLayout`) in DXF read/write so Codes `1`, `70`, and `76` never collide, emit real layout plot settings and `ACAD_PLOTSETTINGS` named setups, and sync `LIMMIN`/`LIMMAX` (`10/20`, `11/21`).
2. **Phase 1: Canvas Sheet Visualization (`PaperSheetGeometry`)**
   * Compute and render the non-printing physical paper sheet (`DXF 44 x 45` converted by `Code 72` and scaled by `143 / 142`), drop shadow, and dashed printable margin box with `[L, B, R, T]` permuted across all four `PlotRotation` states (`Code 73 = 0..3`) and origin anchored per `PLOTOFFSET`.
3. **Phase 2: Device Catalog, Validator Engine, and Page Setup Dialogs (`PlotSettingsValidator`)**
   * Implement `PlotDeviceCatalog` (virtual devices with fixed `referenceDPI`, e.g., `200 DPI` for `DWG To PDF.pc3`, plus unmatched foreign plotter name preservation) and `PlotSettingsValidator` (`PAPERUPDATE`, centering math, `What to plot` enable/disable rules).
   * Build the **Page Setup Manager**, **New Page Setup Dialog**, and **Page Setup Dialog Box** (with live `Partial Preview`), and wire up `PAGESETUP` and the five plot system variables.
4. **Phase 3: Plot Styles (`.ctb`/`.stb`), Built-In PDF Driver, `PLOT`, and `PREVIEW`**
   * Implement the PIAF/zlib `.ctb`/`.stb` parser and shared pen-mapping helper for both live on-canvas `ShowPlotStyles` (`Display plot styles`) and `PDFExporter` (`PlotPlotStyles`).
   * Upgrade `PDFExporter` to honor exact paper size, printable clipping, plot area, scale, offset, rotation, lineweights, and `DrawViewportsFirst`, and ship the `PDF Options`, `PLOT`, and live-canvas `PREVIEW` workflows.
5. **Phase 4: CLI State Machines & External Import (`-PAGESETUP`, `-PLOT`, `PSETUPIN`, `-PSETUPIN`)**
   * Implement the command-line prompt state machines for `-PLOT`, `-PAGESETUP`, and `-PSETUPIN`, external drawing `ACAD_PLOTSETTINGS` import (`PSETUPIN` / Manager `Import...`), and folder openers (`STYLESMANAGER`, `PLOTTERMANAGER`).
