# Hatch patterns

Zephyr scans this folder, a `Patterns` folder next to the executable, the
application resources folder, and the user Application Support
`Zephyr/Patterns` folder for AutoCAD-compatible `.pat` files.

Bundled libraries:

- `acadlt.pat`
- `acadltiso.pat`

Additional `.pat` files placed in any scanned folder appear in the HATCH
pattern search after clicking **Reload**.
